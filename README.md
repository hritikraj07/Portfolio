## 💻 Running Locally

No complicated build tools or package managers required. Simply run:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/hritikraj07/PORTFOLIO.git
   cd PORTFOLIO
   ```

2. **Open in any modern browser**:
   - Double-click `index.html`, or
   - Use VS Code's **Live Server** extension, or
   - Start a quick Python HTTP server:
     ```bash
     python -m http.server 8000
     ```
   - Visit `http://localhost:8000` in your web browser.
